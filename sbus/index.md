# Business Units (SBUs)

Neo Genesis runs 11 live business units:

- [ur-wrong](/sbus/ur-wrong.md) — UR WRONG: AI debate platform that generates arguments on both sides of a question.
- [toolpick](/sbus/toolpick.md) — ToolPick: B2B SaaS comparison engine that analyzes and compares tool stacks.
- [reviewlab](/sbus/reviewlab.md) — ReviewLab: AI product review magazine producing data-driven analysis.
- [kott](/sbus/kott.md) — K-OTT: Korean OTT (streaming) recommendation platform.
- [whylab](/sbus/whylab.md) — WhyLab: Causal inference platform for data analysis.
- [ethicaai](/sbus/ethicaai.md) — EthicaAI: AI ethics research project (BETA).
- [finstack](/sbus/finstack.md) — FinStack: Fintech tool and API reviews.
- [aiforge](/sbus/aiforge.md) — AIForge: Enterprise AI solution benchmarks.
- [sellkit](/sbus/sellkit.md) — SellKit: E-commerce tool reviews.
- [deploystack](/sbus/deploystack.md) — DeployStack: DevOps platform comparisons.
- [craftdesk](/sbus/craftdesk.md) — CraftDesk: Design tool reviews.
